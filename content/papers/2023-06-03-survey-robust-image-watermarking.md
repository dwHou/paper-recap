## 核心方法

归纳为两类：

- single-stage-training (SST)：比如单独训练嵌入网络，单独训练提取网络。
  - Trained detection network (TDN)
  - Trained embedding network (TEN)
- double-stage-training (DST)：联合训练嵌入和提取网络。(更先进)
  - embedding model
  - detection model
  - loss function
  - attack training
