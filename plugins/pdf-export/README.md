# PDF export plugin

在线按需导出当前笔记。构建时只接入按钮、JS 和 CSS；不会打开浏览器、遍历笔记生成 PDF、生成下载清单或建立 PDF 缓存。点击「导出 PDF」后，插件复制当前已经渲染的正文到临时打印文档，调用浏览器原生打印，在窗口中选择「另存为 PDF」。

## 使用

在仓库根目录运行原来的命令即可，Python 标准库会完成网站构建和插件接入：

```sh
python3 scripts/build_site.py
python3 -m http.server 8000 --directory dist
```

刷新网站，打开任意笔记，点击右上角「导出 PDF」。首次点击只需等待这一篇笔记的字体、图片和图表准备完成。打印窗口建议启用背景图形、关闭页眉页脚，并选择保存为 PDF；纸张和缩放由浏览器窗口控制。

普通网站不能替用户静默控制保存路径和打印设置，因此此功能会弹出浏览器原生保存窗口。无需 Node.js、npm、Playwright、浏览器二进制安装或后台服务。公式、图表和字体继续复用原网站及其 CDN 资源。

## 版式与例外

- 复用当前正文、KaTeX、代码高亮和 Mermaid SVG，保留可搜索文字；只处理打开的这一篇笔记。
- 沿用当前明暗主题；即使从手机页面导出，正文也固定为 820px 桌面宽度、76px 内边距和桌面标题字号。原笔记的主题、滚动位置、目录状态、图片和正文不会被更改。
- 默认页面为 820×1160 CSS px、上下各 24px 留白，接近 A4 比例但并非标准 A4 物理尺寸。用户在打印窗口选择其他纸张、缩放和背景设置时，输出也会随之变化。
- 关闭、导出和放大按钮隐藏，文章目录和 Mermaid 源码折叠区隐藏。图片保留，标签保留外观，论文和跨笔记链接仍可使用。
- PDF 采用分页布局；段落、长列表、代码、表格可以跨页。标题尽量与下文同页，普通图片、图表和表格行尽量保持完整，超长表格行仍可能被浏览器拆分。
- 超长代码、连续文字和网址会换行；超宽表格和公式按比例缩小；超高图片或图表缩小适应单页。这些调整会改变局部换行或字号，并在「说明」中列出。
- GIF 转换成静态帧：支持 ImageDecoder 的浏览器（例如 Chrome）取第一帧，其他浏览器取已解码的静态帧。
- X 等外部嵌入显示说明和原始链接，不在 PDF 中播放。单张图片超过 1 亿像素会停止准备并提示重试。
- 浏览器、系统字体和打印设置可能造成差异，不承诺所有平台逐像素相同。推荐使用桌面 Chrome 的「另存为 PDF」。

准备失败、超时或准备过程中切换笔记时，会清理临时文档；缺图、公式或图表失败时不会继续调用打印。关闭或取消打印后同样清理，可再次导出。

## 禁用、移除与配置

只构建基础网站：

```sh
python3 scripts/build_site.py --skip-plugins
```

或设置环境变量 `ENABLE_PDF_EXPORT=false`。GitHub Actions 已将同名仓库变量传入构建步骤。`--check` 始终只校验内容，不接入插件。

永久移除时删除整个 `plugins/pdf-export/` 目录，再正常构建、部署即可；构建器会自动跳过不存在的插件。不需要恢复原来的业务渲染代码，也不会留下 PDF 产物。

可在当前页面调用 `window.PaperRecapPdfExport.destroy()` 临时移除按钮和事件监听。Fork 后修改本目录 `config.json` 的 `publicBaseUrl`，用于 PDF 中指向公开站点的链接。

## 开发验证

Playwright 1.62.1 是测试专用开发依赖，正常构建与在线使用均不需要它。只有运行浏览器集成测试时才安装：

```sh
npm ci --prefix plugins/pdf-export --ignore-scripts
cd plugins/pdf-export
npx --no-install playwright install chromium
cd ../..
node plugins/pdf-export/tests/browser.cjs
```

```sh
python3 -m unittest discover -s tests
node --test tests/*.test.js
```

浏览器测试在隔离的临时站点验证按需准备、固定宽度、原文不变、明暗主题、GIF、动态嵌入、分页、取消/失败清理及笔记切换，并仅为该测试笔记生成一份原生 PDF 供版面验证。测试文件在被忽略的 `tmp/` 中，不会发布。验证结果见 `VERIFICATION.md`。

## 安全复核

入口为现有公开笔记 DOM、固定插件文件及 HTTPS 链接配置。复用原有内容转义，以 DOM API 构造临时文档；不执行笔记 HTML，不上传笔记，不新增账号、密钥、认证会话、权限系统、遥测或用户数据存储。

打印 iframe 仅允许同源访问和原生打印弹窗，不允许执行脚本；只复制现有同源/KaTeX 样式。文件打包拒绝路径穿越和符号链接，Python 构建使用固定脚本路径及参数数组。SHA-256 只用于资源缓存版本。错误提示不包含笔记正文；临时 DOM、事件和超时资源会清理。请复核这些边界、测试结果和测试依赖版本；实际 PDF 由用户保存、保留或删除。
