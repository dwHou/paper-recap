# Verification

验证日期：2026-11-16。当前实现为在线按需导出；以下结果针对本版，不依赖预生成 PDF。

## 构建与单元测试

- 普通命令 `python3 scripts/build_site.py` 构建 71 篇笔记并接入插件，最新本机耗时约 0.46 秒（macOS arm64）。它只调用 Python 标准库，不启动浏览器或逐篇生成 PDF。
- 输出插件目录只有 `plugin.css`、`export.css`、`prepare.js`、`plugin.js` 四个资源；整个 `dist/` 没有 PDF 或 PDF 清单。
- `--skip-plugins` 实际构建后确认插件目录与引用被清除，再普通构建成功恢复按钮资源。
- Python 测试 10 项通过：核心资产版本、构建与插件调用顺序、check/skip、缺失/禁用插件、无 shell 的固定 Python 调用、错误状态、路径穿越与符号链接拒绝、重复打包不重复引用、仅打包资源。
- 原有 JavaScript 测试 22 项通过。OpenSpec 严格校验和 `git diff --check` 通过。

## 在线浏览器验证

使用测试专用 Playwright 1.62.1 与 Chromium 151，运行 `node plugins/pdf-export/tests/browser.cjs`：

- 打开笔记时只有一个按钮，没有打印 iframe，也没有请求 PDF 或 manifest。
- 点击后仅准备当前笔记，未包含另一篇笔记标记；只有资源准备完成才调用打印。
- 固定正文 820px，保留公式、代码、两张 Mermaid SVG 和图片；按钮、目录、源码和外部 iframe 不进入打印文档。原正文 HTML 保持不变。
- 手机宽度页面保持桌面打印宽度与 64px 标题字号；深色主题保留，页面按钮不遮挡标题。
- GIF 第一帧像素核对为预设红色；超宽代码、网址、表格、公式、超高流程图及外部嵌入触发预期说明。
- afterprint 清理打印 iframe 并恢复按钮，再次导出成功；该事件用于成功保存和取消后的同一清理路径。
- 缺图与导出样式加载失败均不调用打印，清理后可重试。
- 准备过程中再次点击不创建第二个任务；切换笔记会取消准备，未打印另一篇或旧笔记。浏览器后退不重复添加按钮。
- destroy 清除按钮、事件和临时文档，原站仍能打开笔记。

为避免自动弹出系统窗口，集成测试在原生 `window.print()` 调用边界计数；另将已经准备好的同一打印 DOM 交给 Chromium 原生 PDF 输出作版面验证。测试笔记为 11 页，可提取文字，最后一页包含 `FINAL_RUNTIME_MARKER`，不含另一篇标记。检查了长图、GIF 静态帧、代码和分页样本。

还在实际的 Noise Schedules 笔记上验证了在线按钮、当前篇末尾章节保留和打印调用，并查看了其原生 PDF 版面中的标题、颜色、公式与正文。测试没有批量渲染其他笔记。

## 范围与安全复核

当前为本地实现与验证，未推送或触发 GitHub Actions。系统打印窗口中的用户操作未自动执行；纸张、背景图形、页眉页脚、缩放和系统字体可能影响最终输出，详见 README。

复核项包括：固定 Python 入口与路径/配置校验、iframe 同源和弹窗权限且无脚本权限、DOM 克隆而非原文 HTML 注入、无上传/新凭证/会话/私密存储、泛化错误提示、SHA-256 资源版本、准备超时和 afterprint 清理、测试依赖仅用于开发。实际 PDF 保留/删除由用户保存行为决定。

QA PDF 和截图都位于被忽略的 `tmp/`，不属于发布产物。正常构建和线上导出均无需 Playwright 或构建端 Chromium。
